# Weather Town

A clean, responsive weather application built with Vanilla JavaScript, HTML, and CSS. It fetches real-time data and a 5-day forecast using the OpenWeatherMap API. 

## Features
- **Current Weather:** Displays temperature, conditions, humidity, wind speed, visibility, and pressure.
- **5-Day Forecast:** Shows daily temperature projections.
- **Geolocation:** Quickly fetch weather for your current location using browser APIs.
- **Responsive Design:** Clean, dark-themed UI that works across desktop and mobile devices.

## Tech Stack
- HTML5
- CSS3 (CSS Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (ES6+, Fetch API, Async/Await)
- OpenWeatherMap API

## Setup
1. Clone the repository.
2. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api).
3. Open `script.js` and update the `API_KEY` variable with your key.
4. Open `index.html` in your browser.
